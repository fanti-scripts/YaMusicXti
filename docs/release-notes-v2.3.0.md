# Фон Яндекс Музыки 2.3.0

Каталог из 50+ тем для обложек и статус Discord с текущим треком и кнопками.

## Что нового

- **Каталог тем обложек** — больше 50 градиентных тем: от ч/б и сепии до
  неона, северного сияния и космической пыли. У каждой плитки превью-градиент,
  номер, название и HEX-коды обоих цветов.
- **Дуотон без «просветов»** — обложка переводится в ч/б и раскрашивается
  выбранным градиентом: тёмный тон уходит в тени, светлый — в света. Исходный
  цвет картинки не проступает ни в покое, ни на наведении. Своя аватарка в
  левом меню остаётся цветной.
- **Discord Rich Presence** — в статусе видно название трека, исполнителя,
  обложку и живой прогресс. Две кнопки: **«Скачать мод»** на этот репозиторий
  и **«Найти трек»** в Яндекс Музыке.
- **Работает из коробки** — Application ID и логотип мода уже вшиты, создавать
  своё приложение в Discord не нужно. Когда ничего не играет, в статусе
  показывается логотип мода. Свой Application ID можно вписать в панели «Фон».
- **Никаких токенов** — связь идёт по локальному каналу Discord IPC, логин
  и пароль не используются. На паузе к исполнителю добавляется «· пауза»,
  таймер прогресса скрывается.
- **Правильная длительность** — Яндекс Музыка играет через MediaSource, и
  `audio.duration` у неё часто равен длине буфера. Мод берёт настоящую
  позицию и длительность из `mediaSession.setPositionState`, поэтому прогресс
  в Discord совпадает с плеером.
- **Панель «Фон»** — новый блок **Discord** с переключателем, полем
  Application ID и живым статусом подключения.

## Установка

1. Скачай `YandexMusicBackground-Setup-2.3.0.exe` из этого релиза.
2. Запусти и нажми **Установить**.
3. Открой вкладку **Фон** в боковом меню.
4. Статус Discord уже включён. Если хочешь своё название приложения — создай
   его на [discord.com/developers/applications](https://discord.com/developers/applications),
   скопируй **Application ID** и вставь в блок **Discord**.

Если Музыка уже запущена, установщик сам попросит её закрыть и перезапустит.

## Требования

- Windows 10/11
- Яндекс Музыка для Windows (проверено на 5.128.0)
- .NET Framework 4.x (уже есть в Windows)
- Discord для Windows — только если нужен статус

## Важно

- Неофициальный мод, не связан с Яндексом.
- После обновления клиента запусти установщик ещё раз — он перепатчит новую версию.
- Все изменения обратимы кнопкой **Удалить**.
- После патча exe теряет подпись Яндекса; антивирус может спросить подтверждение.
- Кнопки в статусе Discord видит только другой человек, открывший твой профиль:
  у себя в своём статусе их не видно — это ограничение Discord. В веб-версии
  и на телефоне кнопки тоже могут не отображаться.
