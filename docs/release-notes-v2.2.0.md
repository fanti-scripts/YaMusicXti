# Фон Яндекс Музыки 2.2.0

Галерея фонов с контекстным меню, честный разбор Wallpaper Engine архивов
и самообновление установщика с GitHub.

## Что нового

- **Правый клик по плитке в «Мои фоны»**: свойства файла, «Открыть архив»,
  «Показать в проводнике», «Удалить». Свойства считаются из самого файла:
  разрешение, кадры/с, длительность, кодек, битрейт, размер, для `.zip` —
  число файлов и разрешение исходной текстуры сцены.
- **Разбор архивов по приоритету**: видео → исходная текстура из `scene.pkg`
  → превью → любая картинка. Больше не ставится `preview.gif` низкого
  разрешения вместо исходника.
- **Папки разделены**: картинки и видео — в `%APPDATA%\YandexMusic\wallpapers`,
  `.zip` и `.html` — в `%LOCALAPPDATA%\YandexMusic-bg\archives`. Архивы
  переезжают туда автоматически и остаются в галерее.
- **Масштаб «Умно»** решает по каждому кадру: близкие пропорции заполняют окно
  с лёгкой обрезкой, сильно другие показываются целиком на размытой подложке.
- **Исправлен z-index плеера** — ползунок громкости больше не уезжает под
  панель «Фон».
- **«Показать в проводнике»** через `shell.showItemInFolder`, с фолбэком на
  `explorer.exe`; «Открыть архив» — с фолбэком на `cmd /c start`.
- **Самообновление**: установщик проверяет `releases/latest`, скачивает новый
  exe в `%LOCALAPPDATA%\YandexMusic-bg\updates`, запускает его с `--wait-pid`
  и передаёт работу. Новые ключи CLI: `--check-update`, `--update`.

## Установка

1. Скачай `YandexMusicBackground-Setup-2.2.0.exe` из этого релиза.
2. Запусти и нажми **Установить**.
3. Яндекс Музыка запустится с вкладкой **Фон** в боковом меню.

Если Музыка уже запущена, установщик сам попросит её закрыть и перезапустит.

## Требования

- Windows 10/11
- Яндекс Музыка для Windows (проверено на 5.127.0)
- .NET Framework 4.x (уже есть в Windows)
