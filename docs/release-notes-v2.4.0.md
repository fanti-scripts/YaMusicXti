# YaMusicXti 2.4.0

Мод вырос из патча с фонами в полноценный набор функций, поэтому сменил имя:
**Фон Яндекс Музыки → YaMusicXti**.

## Что нового

- **Новое имя и установщик.** `YaMusicXti.exe`, `YaMusicXti.cmd`, окно установщика
  и заголовки — всё под новым именем. Репозиторий переехал на
  [fanti-scripts/YaMusicXti](https://github.com/fanti-scripts/YaMusicXti).
- **Discord: Application ID зашит в мод.** Поле ввода и кнопка «Сохранить»
  убраны из панели «Фон». Статус всегда идёт через приложение мода, подменить
  его нельзя. Свои ID из старых конфигов игнорируются и перезаписываются.
- **Перенос настроек.** При первом запуске папка `%LOCALAPPDATA%\YandexMusic-bg`
  автоматически переименовывается в `%LOCALAPPDATA%\YaMusicXti` — фоны,
  настройки и кэш остаются на месте.
- **Обновления** теперь тянутся из нового репозитория.

## Установка

1. Скачай `YaMusicXti-Setup-2.4.0.exe` из этого релиза.
2. Запусти и нажми **Установить**. Яндекс Музыка закроется и откроется заново
   уже с модом.
3. Удалить мод можно той же кнопкой **Удалить** — клиент вернётся к исходному
   состоянию.

Исходники и документация: https://github.com/fanti-scripts/YaMusicXti
