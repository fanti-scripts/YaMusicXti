# Фон Яндекс Музыки 2.0.0

Самодостаточный установщик мода: картинка, GIF или видео на всё окно Яндекс Музыки.
Python и PowerShell в рантайме не нужны — всё внутри exe.

## Что нового

- Установщик переписан на C# (WinForms), интерфейс на русском.
- Патчер `app.asar` и переключение Electron fuse портированы с Python на C#.
  Результат патча проверен побайтово против старой версии.
- Поддержка актуальной Яндекс Музыки **5.127.0**.
- Исправлена отрисовка карточек и подписей в окне установщика.
- Установка, удаление и повторная установка не портят оригинальные бэкапы.
- Вкладка **Фон** внутри приложения: превью, drag & drop, ссылка на файл,
  пресеты, слайдеры, адаптивный фон по обложке трека.

## Установка

1. Скачай `Фон Яндекс Музыки.exe` из этого релиза.
2. Запусти и нажми **Установить**.
3. Яндекс Музыка запустится с вкладкой **Фон** в боковом меню.

Если Музыка уже запущена, установщик сам попросит её закрыть и перезапустит.

## Требования

- Windows 10/11
- Яндекс Музыка для Windows (проверено на 5.127.0)
- .NET Framework 4.x (уже есть в Windows)

## Важно

- Неофициальный мод, не связан с Яндексом.
- После обновления клиента запусти установщик ещё раз — он перепатчит новую версию.
- Все изменения обратимы кнопкой **Удалить**.
- После патча exe теряет подпись Яндекса; антивирус может спросить подтверждение.
